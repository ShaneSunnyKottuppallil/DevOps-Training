Create secret file for db and app and apply them,
first create and apply db secret and then create and apply app secret.


pass app secrets with base64 encoded values.

appsecret.yml
apiVersion: v1
kind: Secret
metadata:
  name: appsecret
type: Opaque
data:
  DB_NAME: 
  DB_PORT: 
  DB_PASSWORD: 
  DB_USER: 
  DB_HOST: 



similarly pass db sercets with base64 encoded values.

dbsecret.yml
apiVersion: v1
kind: Secret
metadata: 
   name: dbsecret
type: Opaque
data:
   MYSQL_DATABASE: 
   MYSQL_PASSWORD: 
   MYSQL_ROOT_PASSWORD: 
   MYSQL_USER:
